  - Impact: Disposable-gate evidence from one worktree can authorize execution in a materially different target context without producing `provider-execution-context-drift`, defeating the P0 context-binding safety gate.
  - Fix: Make the probe/fingerprint target-cwd aware and bind every provider input that can affect the invocation, failing closed when any relevant input is unreadable. Where the exact provider supports verified isolation flags, prefer isolating those inputs and bind the isolation argv in both gate and production plans.   - Fix: Reconcile indeterminate items when either exact selector is present. On exact transcript corroboration, promote the proven selector into the outcome shape needed for `mapped`; preserve non-retryability. Add expected-only mapped/unresolved/ambiguous tests.

  - Impact: Expected failure paths can leave disposable provider sessions/projects behind with no auditable cleanup disposition, contrary to the gate's cleanup-before-finalization contract.
  - Fix: Track partial gate state from fixture creation onward and always invoke the documented provider-owned cleanup that is possible for known IDs/fixture paths. Finalize an inconclusive receipt with exact redacted cleanup outcomes before returning; never direct-unlink provider state.
