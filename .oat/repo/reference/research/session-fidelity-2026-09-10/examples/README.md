# Synthetic examples

All examples were authored for this packet. They contain no captured user conversation, private code, credentials, or real tool execution. Provider IDs, paths, commands, outputs, and timestamps are illustrative.

`native/` contains one example per observed schema fragment. A record example does not represent a full session; some pairs, such as a result without its preceding call, are intentionally incomplete demonstrations of a single carrier.

`proposed/activity-report.json` demonstrates the optional activity representation with one Codex call/result pair. The error is based on parsed output text and is labeled accordingly, rather than presented as independently measured process telemetry.
