### Medium

- **M1: Raw-byte prefilter drops valid JSON-escaped conversation matches** (`src/skills/session-search/src/lib/scan.ts:60`).
  `isPrefilterSafe` judges only the query. An ordinary ASCII literal is allowed, but JSON can represent its characters with Unicode escapes or an escaped slash. For example, decoded `perceive now` stored as `\u0070erceive now` matches the Node classifier and does not match the raw-byte `rg` query. The resulting file exclusion loses the session. This affects `--no-deep` directly and the default ladder whenever another cheap-tier candidate prevents the deep retry.
  The generated CLI reproduced exit 2 and zero files scanned with `rg`, versus exit 0 and one result without it. A second default-tier corpus contained a history match for `vetting` plus a target whose `perceive` and `vetting` were Unicode-escaped. Accelerated search returned only the history candidate; Node-only search returned the target first and the history candidate second.
  Preserve a provable candidate superset. Either scan decoded text without this prefilter or also retain files containing JSON escape representations that can hide an otherwise safe query. Extend the existing accelerated/fallback parity case with escaped ASCII and `\/`, including a cheap-tier competing hit so the automatic deep retry cannot conceal the defect.
  Requirement: design content-scanner superset invariant and discovery's missing-tool fallback equivalence.

### Low

- **L1: A generated tail title overrides a custom title found in the prefix** (`src/skills/session-search/src/lib/adapters/claude-code.ts:318`).
  `titleFor` returns any tail title immediately. A custom title in the prefix therefore loses to an `ai-title` in the tail once enough conversation separates them, even though `pickTitle` gives custom titles precedence. A synthetic transcript with an initial `Custom unique title`, a 600,000-character message, and a final `Generated newer title` returned the generated title. Metadata search for the user's custom title can then miss the session.
  When a truncated tail has only a generated title, inspect the bounded prefix and preserve custom-title precedence across both reads. Cover the two-window case in the existing title-selection test.

- **L2: Metadata-only Codex results discard known archive and child facts** (`src/skills/session-search/src/lib/pipeline.ts:513`; `src/skills/session-search/src/lib/adapters/codex.ts:859`).
  SQLite parsing retains `archived`, `parentId`, title, and first message, but metadata hits lose those facts and the orphan-session branch hardcodes `archived: false`, `isSubagent: false`, and `parentSessionId: null`. A temporary real SQLite database with an archived `thread_spawn` child and no rollout returned that child as an ordinary, unarchived session, with null title and first prompt despite both being indexed. Metadata-only children consequently lose their labels and cannot participate in parent roll-up.
  Carry indexed session facts through the adapter boundary and use them when synthesizing results without transcript files. Preserve orphan child labeling when the parent is unavailable, and include indexed parents when available. Test an archived child whose rollout has been pruned.

- **L3: Remote history fallback truncates away the match and resume identifier** (`src/skills/session-search/references/remote-fallback.md:99`).
  The recipe truncates the beginning of the entire matching JSON record with `cut -c1-400`. For a long Claude prompt whose sought phrase and `sessionId` occur later, the output loses both. A synthetic history record with 560 characters of padding reproduced a 400-character output containing neither the matched phrase nor its session identifier. The instructions then cannot map this reported hit to a resumable session. The adjacent SQLite query also matches `first_user_message` while returning only a title excerpt.
  Extract the session identifier and project separately and bound an excerpt around the actual matched prompt or title text. Include a first-message excerpt for SQLite first-message matches. Preserve the existing shell-quoting and agent redaction rules.
