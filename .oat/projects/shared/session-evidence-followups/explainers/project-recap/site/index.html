Key agent decisions

Freeze before interpretation

Retro runs from a different known native session and analyzes one frozen target pair. Later live records cannot silently enter the episode under review.

Preserve native meaning

Identity, origin, availability, invocation, outcome, and usage remain separate. Unknown evidence stays unknown; the system does not invent totals, prices, versions, human authorship, or causality.

Capture once, derive a pair

session-export-transcript --activity-output reads one exact native snapshot and derives both the sanitized narrative and sensitive activity JSON from it.

Keep rich capture opt-in

Comprehensive supported invocation capture is explicit. Ordinary Observer and narrative defaults remain compact, with bounded previews and visible coverage limits.

Boundary

“Comprehensive” means every supported invocation found in the captured bytes. It does not prove that a provider recorded every action or that the target session ended.

As-built architecture

Native records enter one shared normalization layer. Observer consumes the compact, metadata-safe projection, while an explicit exporter path freezes the richer exact-session evidence that Retro later reviews.
