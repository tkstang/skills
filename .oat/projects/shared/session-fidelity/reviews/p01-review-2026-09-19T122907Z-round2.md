  (`src/skills/session-observer/src/lib/watch.ts:1332`)

    and emits `WATCH_TRANSCRIPT_PATH_UNAVAILABLE` with instructions to reset
    the session state. That is correct for `ENOENT`/`ENOTDIR`, but the same path
    also handles transient descriptor pressure, permission failures, and other
    filesystem errors. The watcher still exits safely and preserves the saved
    offset, but the diagnostic hides the real cause and can lead an operator to
    reset a valid saved position and replay already delivered records.
  - Fix: preserve the current missing-path error and scoped reset/re-arm
    guidance for `ENOENT`/`ENOTDIR`. For other failures, surface the original
    error code/message and recommend retrying or repairing the filesystem
    condition without resetting session state. Add a dependency-injected stat
    regression proving a non-missing error produces one error event, leaves
    state unchanged, and omits reset guidance.
