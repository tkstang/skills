### Important

- **Cross-chunk frames are accumulated with quadratic copying** (`src/transcript/core/cursor-frames.ts:171`)
  - Issue: Every stream chunk without a newline rebuilds `carry` with `Buffer.concat([carry, suffix])` (lines 171-175). Once a newline arrives, the implementation builds another full `contentBytes` buffer and then copies it again into `rawFrameBytes` (lines 179-185). A large JSONL record or growing partial tail therefore incurs repeated full-prefix copies, quadratic copy work across chunks, and multiple simultaneously live frame-sized buffers. This conflicts with p01-t02's streaming boundary and NFR5/design requirements that changed transcripts be processed without a second unbounded content copy. The committed tests contain no frame large enough to cross the stream's chunk boundary, so this path is not protected.
  - Fix: Accumulate cross-chunk segments as a list plus total length and concatenate once when the physical frame closes (or once to represent a partial tail). Update the safe-prefix hash with the frame segments and newline separately so a second `rawFrameBytes` copy is unnecessary. Add a regression using a frame larger than several stream chunks and assert exact byte ranges, hashes, callback order, and partial-tail behavior.
  - Requirement: NFR5; p01-t02

### Medium

- **A mixed automatic-control user record erases genuine human activity** (`src/transcript/core/cursor-analysis.ts:290`)
  - Issue: The analyzer treats the entire user record as automatic when any text block parses as an automatic envelope, and the `else` prevents that frame from entering `humanRecordIndexes` even when another block contains genuine human text (lines 290-300). `hasAutomaticControlInput` then also influences acknowledgement classification (lines 306-309). A direct probe with one envelope block plus one human-text block produced `humanRecordIndexes: []`, unlike the shared normalizer's block-level envelope classification and the design requirement to distinguish genuine user activity from synthetic control input.
  - Fix: Classify user blocks individually. Retain the automatic-control flag when an envelope is present, but also record human activity when any supported non-envelope user text exists; do not let automatic acknowledgement suppression override a turn that contains genuine human input without an explicit precedence rule. Add mixed-block and automatic-then-human record tests.
  - Requirement: FR3; p01-t03, p01-t04
