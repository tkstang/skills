    `{"lease_id":"lease-actual-123"}` return no findings. In addition,
    `changedMarkdownFiles()` diffs against `HEAD`
    (`scripts/validate-cursor-evidence.mjs:202`), so a clean committed Phase 5
    checkout scans the runtime reference and fixtures but not the changed user
    guide, engineering, or skill Markdown. The capability-matrix check also
    requires only global presence of labels and explicitly blesses
    `measured-structural-only` (`scripts/validate-cursor-evidence.mjs:141`)
    even though the governing spec/design taxonomy is
    `live-validated`, `automated-only`, `documented-but-unvalidated`,
    `unavailable`, or `unsupported`
    (`.oat/projects/shared/cursor-collaboration-reliability/design.md:921`).
    The validator therefore passes without enforcing p05-t01's raw-identity,
    changed-doc, and honest-label contracts.
  - Fix: Recognize quoted JSON/YAML/Markdown identity assignments (prefer a
    small structured/key-aware scanner where possible), add negative tests for
    quoted session/conversation/generation/lease values, resolve the default
    committed review range from an explicit base or merge base instead of
    `HEAD`, and validate every matrix row against one canonical evidence-label
    enum and its required fields. If the narrower
    `live-sanitized`/`measured-structural-only` taxonomy is intentional, align
    `spec.md` and `design.md` explicitly rather than silently changing the
    contract.
  - Requirement: FR9, NFR6

  - Fix: Make each live row assert the exact public claim it promotes (including

    weaker condition actually checked. Add mocked negative tests for wrong
